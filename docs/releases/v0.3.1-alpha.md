## Veigar K643 Configurator v0.3.1-alpha

A corrective rebuild of v0.3.0-alpha focused on startup reliability and diagnostics.

### Startup and compatibility
- Replaced implicit WPF StartupUri launch with explicit startup and error handling.
- Startup and unhandled UI exceptions now produce a readable message and a detailed local log.
- Error logs are written to %LOCALAPPDATA%\VeigarConfigurator\Logs; no logs are uploaded.
- Dark Windows title-bar styling is optional and cannot prevent the main window from opening.
- Raw Input registration failures are isolated and reported without blocking the application.
- Added an application configuration file declaring .NET Framework 4.8.
- Added Start-VeigarConfigurator.cmd to check for .NET Framework 4.8 before launching.
- The portable ZIP includes the EXE configuration file and launch helper.

### Retained features
- The v0.3.0-alpha RGB editor, layers, animation, key-reactive lighting, audio peak meter and local profiles remain included.

### Testing status
- Build and packaging are performed by Windows GitHub Actions.
- Startup diagnostics are intended to identify runtime failures on the target PC.
- Physical K643 operation of the v0.3.0 feature set still requires user-side validation.

### Run instructions
1. Extract the complete ZIP archive to a normal folder.
2. Run Start-VeigarConfigurator.cmd.
3. Close Redragon's configuration utility before testing the keyboard.
4. If startup fails, attach the log path displayed in the error dialog.

**Platform:** Windows 10/11 x64 with .NET Framework 4.8 or newer.

This is an experimental pre-release, not a stable release.
