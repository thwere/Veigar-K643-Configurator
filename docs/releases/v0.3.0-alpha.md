## Veigar K643 Configurator v0.3.0-alpha

The expanded RGB Studio and lighting workspace, with corrected audio-level display binding.

### Added
- Dark multi-tab WPF interface and dark Windows title bar.
- Full 126-slot RGB matrix editor with per-slot colour assignment.
- Static, gradient, animation, audio-reactive and key-reactive lighting layers.
- Layer opacity and Replace / Add / Max compositing.
- Animation frame capture and playback.
- Raw Input filtered to USB VID 258A / PID 0049.
- Manual physical key-to-LED-slot calibration.
- Flash, fade and hold-glow key response, with simultaneous mapped keys.
- Windows Core Audio default-output peak meter.
- JSON profiles containing the full layer stack, slot colours, animation frames and key mappings.
- Migration of older v0.2.0-alpha colour profiles.

### Startup and interface reliability
- The audio output level indicator uses a one-way binding because its view-model property is read-only. This prevents a WPF startup binding exception.
- The portable archive includes the .NET Framework 4.8 application configuration and launch helper.

### Performance
- One complete 382-byte HID Feature Report is sent per rendered scene.
- HID writes run away from the WPF dispatcher.
- Audio-reactive updates are sent when output peak level changes meaningfully.

### Hardware status
- User confirmed all keyboard keys illuminated in v0.1.0-alpha.
- The 126-slot editor, manual key calibration, reactive effects, animation and audio meter are new and require additional physical-device testing.
- The slot grid represents protocol slot indices, not a verified physical key diagram.

### Not included
- Ripple / neighbour-ripple pending a verified physical geometry map.
- Audio spectrum and frequency-band analysis.
- Macro editor and software key remapping.
- Installer and updater.

### Important
- Close Redragon configuration software before testing.
- Key input is transient and only accepted from the target K643 VID/PID; typed text is not stored.
- Audio peak values are sampled transiently; audio is not recorded.
- Profiles are local JSON files. Lighting is temporary and no firmware modification is performed.

**Platform:** Windows 10/11 x64.

This is an experimental pre-release, not a stable release.
