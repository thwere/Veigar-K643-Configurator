## Veigar K643 Configurator v0.2.0-alpha

The first expanded RGB Studio build.

### Added
- Custom RGB channel editor with live preview.
- Six-digit HEX colour entry.
- Global brightness control.
- Eight quick colour presets and a lights-off command.
- Local JSON lighting profile save/load.
- Per-operation elapsed-time reporting.

### Performance
- Each global lighting update sends one 382-byte HID Feature Report.
- HID I/O runs on a background task so the WPF interface remains responsive.
- The previous 60-write / approximately 3-second delay loop has been removed.

### Hardware status
- The initial v0.1.0-alpha WPF build successfully lit all keyboard keys during user testing.
- The one-report transport path and the new editor require validation on physical hardware.
- The current UI controls global solid-colour lighting; per-key editing is not included yet.

### Important
- Close Redragon configuration software before testing.
- Profiles are stored locally as JSON and are not written to keyboard memory.
- Lighting settings are temporary.
- No firmware modification is performed.

**Platform:** Windows 10/11 x64.

This is an experimental pre-release, not a stable release.
