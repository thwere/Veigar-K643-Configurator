## Veigar K643 Configurator v0.1.0-alpha

Our first experimental application build.

### Included
- Initial WPF application interface.
- Automatic detection of Redragon Veigar K643.
- HID interface discovery (VID 258A / PID 0049).
- Basic solid-colour RGB preview.
- Red, green, blue and off commands.

### Important
- This is an early experimental build.
- Hardware compatibility has not yet been validated through the new graphical application.
- Close Redragon configuration software before testing.
- RGB preview does not save settings to keyboard memory.
- No firmware modifications are performed.

**Platform:** Windows 10/11 x64.

This release is intended for initial testing and feedback. It is not a stable release.
